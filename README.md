# Support Gate SDK

Клиентские библиотеки Support Gateway — сервиса, который принимает обращения
игроков в поддержку и доставляет их в Jira Service Management. Игра к Atlassian
не обращается: ей нужен только шлюз и один секрет на бэкенде.

| Папка | Что это |
| --- | --- |
| [`js/`](js/README.md) | окно обращения для веб-игр: UMD-бандл, его отдаёт сам шлюз |
| [`unity/`](unity/README.md) | UPM-пакет: клиент и форма для Unity (uGUI и UI Toolkit) |
| [`unity-demo/`](unity-demo/README.md) | Unity-проект: стенд формы без сети и play-mode тесты пакета |
| [`dist/SupportGate-UGUI.unitypackage`](dist/SupportGate-UGUI.unitypackage) | белый и чёрный префабы, графика и шрифт; [подключение](docs/unity-ugui-prefabs.md) |
| [`docs/integration.md`](docs/integration.md) | что сделать на бэкенде игры: токен сессии, подключение SDK |

Этот репозиторий — публикуемый снимок SDK из основного репозитория шлюза;
релиз приходит одним коммитом с тегом `vX.Y.Z`, ручная публикация обновляет
`main` коммитом `SDK snapshot (<коммит источника>)` без нового тега. Правки и предложения —
через issues и pull requests: они переносятся в источник вручную.

## Версия 0.4.1

Исправления вложений в HTML-форме:

- кнопка добавления скрывается при достижении лимита и возвращается после удаления файла;
- файлы, превышающие допустимый размер, отклоняются до добавления в форму;
- отправка недоступна, пока вложения загружаются или не удалось их загрузить.

Лимиты задаются конфигурацией Support Gate. Изменения относятся к JS SDK;
версия Unity-пакета синхронизирована с общим номером релиза.

## Версия 0.4.0

Готовые белое и чёрное uGUI-окна поставляются в
[`SupportGate-UGUI.unitypackage`](dist/SupportGate-UGUI.unitypackage).
Установите Unity SDK через
`https://github.com/hooligapps/support-gate-sdk.git?path=/unity#v0.4.0`,
затем импортируйте архив. Подключение и переход с локальных компонентов Order
описаны в [инструкции](docs/unity-ugui-prefabs.md).

Проверены импорт архива и 6 Play Mode тестов в Unity 6000.6.5f1.
Изменения этой версии относятся к Unity; версия JS-пакета синхронизирована
с общим тегом репозитория.

## Контракт

SDK ходят в шлюз тремя запросами и не зависят от его внутренностей:

- `GET /v1/form` — категории, поля, лимиты вложений, строки интерфейса на
  языке игрока (`locale`, `direction`, `strings`);
- `POST /v1/attachments/presign` и загрузка файла по выданному URL;
- `POST /v1/tickets` — обращение; новый ответ содержит `ticket_id`,
  `status: queued` и `issue_key: null`. Номер Jira появляется после доставки
  воркером; его можно получить через `GET /v1/tickets/{ticket_id}` той же сессией.

Все запросы с токеном сессии, который выпускает бэкенд игры своим секретом —
см. [`docs/integration.md`](docs/integration.md). Истёкшую сессию SDK продлевают
сами через `POST /v1/session/refresh`.

Клиенту без веб-движка библиотека не обязательна: шлюз держит страницу
`/form#token=<jwt>` с той же формой, её достаточно открыть в системном
браузере (в Unity — `SupportGateBrowser.Open`).
