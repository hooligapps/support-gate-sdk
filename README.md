# Support Gate SDK

Клиентские библиотеки Support Gateway — сервиса, который принимает обращения
игроков в поддержку и доставляет их в Jira Service Management. Игра к Atlassian
не обращается: ей нужен только шлюз и один секрет на бэкенде.

| Папка | Что это |
| --- | --- |
| [`js/`](js/README.md) | окно обращения для веб-игр: UMD-бандл, его отдаёт сам шлюз |
| [`unity/`](unity/README.md) | UPM-пакет: клиент и форма для Unity (uGUI и UI Toolkit) |
| [`unity-demo/`](unity-demo/README.md) | Unity-проект: стенд формы без сети и play-mode тесты пакета |
| [`docs/integration.md`](docs/integration.md) | что сделать на бэкенде игры: токен сессии, подключение SDK |

Этот репозиторий — публикуемый снимок SDK из основного репозитория шлюза;
каждый релиз приходит одним коммитом с тегом `vX.Y.Z`. Правки и предложения —
через issues и pull requests: они переносятся в источник вручную.

## Контракт

SDK ходят в шлюз тремя запросами и не зависят от его внутренностей:

- `GET /v1/form` — категории, поля, лимиты вложений, строки интерфейса на
  языке игрока (`locale`, `direction`, `strings`);
- `POST /v1/attachments/presign` и загрузка файла по выданному URL;
- `POST /v1/tickets` — обращение; ответ содержит `ticket_id` и, если Jira
  ответила сразу, ключ задачи.

Все запросы с токеном сессии, который выпускает бэкенд игры своим секретом —
см. [`docs/integration.md`](docs/integration.md).
