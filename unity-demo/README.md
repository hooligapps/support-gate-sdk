# Демо-стенд Support Gate для Unity

Отдельный Unity-проект, который подключает пакет `com.hooligapps.supportgate` из
соседней папки (`file:../../unity`) и показывает форму обращения на обоих
рендерерах — uGUI и UI Toolkit — во всех состояниях: загрузка, форма, ошибки
полей, отправка, «отправлено», ошибка загрузки с повтором.

Данные фиктивные: сеть не используется, ответы отдаёт демо-сервер
(`SupportGateDemoTransport`), включая «хранилище» для загрузки вложений.
Подключение к настоящему шлюзу — снять галку и вписать токен, см. ниже.

## Запуск

1. Открыть папку `unity-demo` в Unity 6000.6.5f1. Готовые префабы проверяются на этой версии.
2. Демо-сцена собирается сама при первом открытии проекта. Если её нет (или
   нужно пересобрать после правок) — меню **Tools → Support Gate → Собрать
   демо-сцену**: сцена создаётся заново вместе с `UIDocument` и `PanelSettings`,
   ссылка на USS пакета проставляется автоматически.
3. Нажать **Play**. Слева — панель управления на IMGUI, справа вверху — кнопка
   «Support», как она стояла бы в HUD игры.

uGUI использует готовые префабы из `Assets/SupportGateUGUI`. В сцене назначены
ссылки на белое окно и чёрный вариант. Переключатель **Light / Dark** меняет тему.

## Что можно потрогать

| Переключатель | Что проверяет |
| --- | --- |
| Light / Dark | Белый и чёрный uGUI-префабы |
| uGUI / UI Toolkit | Одна и та же форма на двух рендерерах |
| Ответ на `/v1/form` | английский, русский, арабский (RTL, шесть форм plural), почта из токена (поле заблокировано), HTTP 500, 401, нет сети |
| Ответ на `/v1/tickets` | принято с ключом Jira, в очереди (без ключа — показывается `ticket_id`), ошибки полей от сервера, 429, 503, нет сети |
| Задержка | Видно ли состояние загрузки и «Отправляем…», не двоятся ли запросы при быстрых кликах |
| Хранилище отвергает файлы | Строка вложения должна исчезнуть, а не остаться «загружается» |
| Хост разрешает показ | Отказ игры показывать окно: пакет не ставит его в очередь и не повторяет |
| Приложить … | Скриншот через `ScreenCapture`, текстовый файл, неподдерживаемый тип и файл больше лимита — два последних отбрасываются до сети |
| «Добавить файлы» в форме | В редакторе — системный диалог выбора файла; в билде демо кладёт скриншот. В игре сюда подключается её пикер (см. README пакета) |

Все события презентера — `Submitted`, `Failed`, `HostRefused`, `Closed` и итог
`Completed` — и все запросы с ответами пишутся в лог внизу панели.

## Тесты

`Assets/SupportGateDemo/Tests/Runtime` — play-mode тесты, которые проходят
сценарии на настоящих вью обоих рендереров через демо-сервер: строки сервера на
экране, зависимые поля, вложение, ошибки полей, повтор после сбоя загрузки, RTL.
Тесты самого пакета (`testables` в манифесте) видны в том же Test Runner.

Из командной строки:

```sh
Unity -batchmode -nographics -projectPath unity-demo -runTests -testPlatform EditMode -testResults /tmp/editmode.xml
Unity -batchmode -nographics -projectPath unity-demo -runTests -testPlatform PlayMode -testResults /tmp/playmode.xml
```

## Префабы и экспорт

[`../docs/unity-ugui-prefabs.md`](../docs/unity-ugui-prefabs.md) описывает
установку, зависимости, жизненный цикл и редизайн.
**Tools → Support Gate → Export uGUI package** собирает архив в `../dist`.
Компоненты формы поставляются через UPM, ассеты через архив.

## Подключение к шлюзу

На компоненте `SupportGateDemoApp`:

1. Снять **Use Demo Server** — стенд перейдёт на `SupportGateUnityWebRequestTransport`.
2. Заполнить **Endpoint** (`https://support.flushee.work`) и **Session Token** —
   JWT, который выпускает бэкенд игры своим секретом (в игре это запрос к своему
   серверу, см. `RequestToken`). Секрет игры в клиент не попадает.

Дальше переключатели «Ответ на …» перестают влиять: отвечает настоящий шлюз, а
обращения попадают в Jira.

## Файлы

| Файл | Что делает |
| --- | --- |
| `SupportGateDemoApp.cs` | Стенд: сборка обоих рендереров, панель управления, лог |
| `SupportGateDemoTransport.cs` | Демо-сервер: сценарии ответов, задержка, «хранилище» |
| `SupportGateDemoCatalog.cs` | Фиктивный `/v1/form` со строками из каталогов шлюза, presign и тикет |
| `SupportGateDemoUGuiFactory.cs` | Кнопка запуска и модальная подложка демо |
| `SupportGateDemoHosts.cs` | Модальный и панельный хосты демо |
| `Editor/SupportGateDemoSceneBuilder.cs` | Меню «Собрать демо-сцену» |
| `Tests/Runtime/SupportGateDemoFlowTests.cs` | Сквозные play-mode тесты на настоящих вью |
